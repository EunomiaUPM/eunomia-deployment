Run it as `./eunomia <command>` (macOS, Linux) or `.\eunomia.cmd <command>` (Windows), or `eunomia` after `pip install -e .`. Every command takes `--help`. For the commands in context, see [Workflows](/docs/cli/workflows).

<Callout type="info">This page is generated from the CLI itself: `python3 cli/tools/gen_cli_docs.py`. CI fails when it is out of date.</Callout>

## `eunomia doctor`

Check Docker, Compose, ports and versions.env.

```text
eunomia doctor [-h] [--images]

options:
  -h, --help  show this help message and exit
  --images    also check every pinned image can be pulled
```

## `eunomia up`

Start the deployment, onboard the participants and populate the catalog.

```text
eunomia up [-h] [--env {standalone,prod}] [--no-onboarding] [--no-catalog] [--pull]
                  [--build]
                  [node ...]

positional arguments:
  node                  authority, provider, consumer, demo, or all (default: all of them)

options:
  -h, --help            show this help message and exit
  --env {standalone,prod}
                        standalone (default): every participant on this host. prod: real servers.
  --no-onboarding       only start the stacks
  --no-catalog          do not populate the provider catalog
  --pull                pull the pinned images before starting
  --build               rebuild the demo factory image
```

## `eunomia down`

```text

  -h, --help         show this help message and exit
```

## `eunomia e2e`

Negotiate, then pull and push data end to end.

```text
eunomia e2e [-h] [--env {standalone,prod}] [--dataset DATASET] [--list-datasets]
                   [--keep-open] [--no-suspend] [--no-data-pull] [--no-push] [-v]
                   [--consumer CONSUMER] [--provider PROVIDER]

options:
  -h, --help            show this help message and exit
  --env {standalone,prod}
                        standalone (default): every participant on this host. prod: real servers.
  --dataset DATASET     substring of the dataset title (default: the demo factory dataset)
  --list-datasets       list the catalog and exit
  --keep-open           leave the pull transfer STARTED
  --no-suspend          skip the suspend/resume leg
  --no-data-pull        skip the data pull through the proxy
  --no-push             skip the push transfer
  -v, --verbose         dump every request and response
  --consumer CONSUMER   consumer to use: an instance name (default: the standalone consumer)
  --provider PROVIDER   provider to use: an instance name (default: the standalone provider)
```

## `eunomia connector`

Extra connectors next to the standalone deployment.

### `eunomia connector add`

Create and start a connector on free ports.

```text
eunomia connector add [-h] [--role {consumer,provider}] [--onboard] [--authority AUTHORITY]
                             [name]

positional arguments:
  name                  default: conn-<random>

options:
  -h, --help            show this help message and exit
  --role {consumer,provider}
  --onboard             register it with the authority once it is up
  --authority AUTHORITY
                        authority to register with (implies --onboard)
```
