---
title: "Deployment"
description: "Run authorities and agents on one machine, or one per server, and manage them all by name."
---

| | Local instances | Production |
| --- | --- | --- |
| Where | this machine, as many as you need | one server per authority or agent |
| For | development, demos, workshops, CI | real data spaces |
| Created with | `eunomia authority add`, `eunomia agent add` | `eunomia prod up agent\|authority` on each server |
| Managed with | the same commands, by name | `eunomia remote add`, then the same commands |
| Identities | `did:jwk`, generated per instance | `did:web` on each domain |
| Secrets | file vault in `instances/<name>/vault/` | HashiCorp Vault with TLS |
| TLS | none | your certificates |
| Compose files | templates in `deployment/instances/` | `deployment/prod/` |

Both use the same images, pinned in `versions.env`, and the same CLI. Local and remote instances can live in one registry: a local agent can negotiate with one on a server.
