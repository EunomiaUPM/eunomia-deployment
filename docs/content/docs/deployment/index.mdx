---
title: "Deployment"
description: "Two ways to run EUNOMIA: everything on one machine, or one participant per server."
---

| | Standalone | Production |
| --- | --- | --- |
| Where | one machine | one server per participant |
| For | development, demos, workshops, CI | real data spaces |
| Identities | `did:jwk` | `did:web` on each domain |
| Secrets | file vault in `vault/` | HashiCorp Vault with TLS |
| TLS | none | your certificates |
| Authority console | open | behind Keycloak and oauth2-proxy |
| Start with | `./eunomia up` | the [production guides](/docs/deployment/production) |
| Compose files | `deployment/standalone/` | `deployment/prod/` |

Both use the same images, pinned in `versions.env`, and the same CLI: `--env prod` switches it to production.
